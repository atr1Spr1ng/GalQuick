# GalQuick

## 开发它的初衷
主要是自己想用哈哈哈哈。
### 起因
在玩黄油的时候，lunatranslator只能实时翻译，太慢了，干正事的时候急不可耐呢~，我就想着把文字根据引擎直接提取出来，丢给AI一股脑给翻译了。
### 色色的时候想看剧情，但是又忍不住ctrl怎么办呢？
emmm，因为我是剧情党，而且众所周知，全CG也只能看CG，并不能按照正常游玩的顺序，看CG对应的SCENE，听语音，从中体会剧情中女主的变化~；
若是一直按CTRL，剧情也看的不舒服，还浪费时间。
### 解决方案
所以我就想着，H-CG对应的SCENE到SCENE之间的文本直接提取出来，以小说形式展示，然后直接跳到下一个H-CG对应的SCENE去观看。
SCENE中间采取实时演示（提前翻译好，然后用lunatranslator的Hook匹配实时语句）
