# GalQuick

> 剧情快速读，CG 慢慢看。

Galgame / 视觉小说剧情加速器。把演出之间的剧情整理成小说式阅读，再衔接原版游戏演出，减少逐句点击和反复快进。

目前是个人开发的初版，**仅实验性支持 AdvHD / WillPlus**，还有不少兼容性和交互问题。欢迎一起完善。

## 为什么做这个

起因很简单：我玩 Galgame 时用 LunaTranslator 逐句翻译，有时候觉得等待有点慢，就想能不能先把文字按引擎提取出来，提前翻译好。

但我又是剧情党。只看 CG 总觉得少了上下文；一直按 Ctrl 快进，剧情也看得不舒服。我想按正常游玩的路线理解故事和角色变化，同时把时间留给想认真看的演出。

于是有了这个想法：

- **演出之间的剧情**，像看小说一样整段阅读。
- **遇到选项**，停下来选择路线。
- **进入演出**，回到原版游戏，保留原来的画面和声音。
- **演出中的字幕**，用 Hook 捕获当前原文，匹配提前导入的译文。

不是单纯跳过剧情，而是把读剧情和看演出的节奏分开。

## 目前能做什么

- 管理本地游戏，解析剧情和路线，不复制整套游戏。
- 导出原文与 AI 提示词，导入翻译结果，不强制使用 API Key。
- 小说式阅读、路线选择和原版演出衔接。
- 本地译文实时字幕，显示人名，并保留可滚动记录。

字幕功能复用用户提供的 [LunaTranslator](https://github.com/HIllya51/LunaTranslator) 安装目录中的 Hook 组件，无需另外启动其主界面。本项目不附带这些组件。

## 怎么用

源码整理中，当前仓库尚未提供完整程序。源码上传后，使用流程为：

1. 安装 Python 3.11 或更新版本，保留 Tcl/Tk 和 Python Launcher。
2. 下载并完整解压源码，双击 `start.cmd`。
3. 添加游戏 → 解析剧情 → 打开阅读器。
4. 需要翻译时，先导出 AI 任务包，再导入返回结果。
5. 需要实时字幕时，在“字幕 Hook”里选择完整的 LunaTranslator 安装目录，并启用连接。

## 还不完善的地方

- 当前只有 AdvHD 适配，不保证所有同引擎游戏都兼容。
- 剧情解析、路线衔接和窗口交互仍需要更多实机反馈。
- 字幕可能漏抓或匹配不到；缺失译文不会自动生成。
- 首次使用前请备份游戏和存档。演出运行时会临时修改脚本资源，正常退出恢复；异常退出后请保留项目目录和备份。
