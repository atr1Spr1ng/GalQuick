# 使用方法

## 启动

1. 安装 Python 3.11 或更新版本，建议 64 位。安装时保留 Tcl/Tk 和 Python Launcher。
2. 完整解压本工具，双击 `start.cmd`。
3. 点击“添加游戏”，选择游戏目录，再点“解析剧情”→“打开阅读器”。

目前仅实验性支持 AdvHD 引擎，不保证所有游戏兼容。

## 导入翻译

点击“一键翻译整部游戏”，导出 AI 任务包。把任务文件和包内提示词交给 AI，拿到结果后导入即可，不需要 API Key。已有兼容译文包也可以直接导入。

## 开启实时字幕（可选）

1. 先导入译文，并准备一个完整的 LunaTranslator 安装包。
2. 点击阅读器中的“字幕 Hook”，选择 LunaTranslator 安装目录。
3. 点击“启用／重连”。以后会记住配置，不用另外打开 LunaTranslator。

请选择完整安装目录，不要单独选择或替换 DLL。不是所有组件版本都兼容。

游戏显示台词后才会收到文本。没有译文时，先检查译文是否导入；必要时在 Hook 设置里选择预览为正文的文本流，再通过“匹配详情”查看原因。

字幕显示人名并保留可滚动记录。匹配不到或缺少译文时会显示原文，不会自动在线翻译。“更多”里可以手动确认演出结束。

## 注意事项

- 首次使用前请备份游戏和存档。演出时工具会临时修改游戏脚本，正常退出后恢复。
- `projects` 文件夹保存配置、译文和备份，不会复制整套游戏。运行时不要删除它；异常退出后也请保留备份。
- 不要分享游戏资源、完整剧情或个人项目数据。
- 启动失败时，把窗口里的错误信息发来反馈，注意遮住个人路径。
